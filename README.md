## About Me

你好，我是 **xsbcme**。  
我主要在做 **Vue / TypeScript 前端工程化**、**npm 生态工具** 和 **Windows x64 / C++ 底层技术探索**。我的项目通常偏实用：要么解决后台系统里的复杂交互，要么围绕包安全、源码产物、进程内存和 PE 结构做工具化实践。

- 主要方向：Vue 管理后台、多标签路由、前端状态与缓存管理
- 工具实践：npm 包分析、Source Map 监控、自动化扫描与报告
- 底层探索：C++、Windows x64、内存读取、PE 文件结构与导入表重建
- 做事偏好：把复杂流程封装成清晰、可复用、能落地的工具
